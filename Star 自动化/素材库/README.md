## 分类与编号

I001—I023 为图片，V001—V013 为视频。编号由原文件名排序首次建立，以标注表固定；新增或改名时先更新标注，避免错配。

原件存于 `原始资料/Star来源/`，保留文件名与字节。缩略图及三帧截图用于检索；所有文件授权状态为待确认。

图片按品牌视觉、App界面、排名与会员、周边、活动路线、球场场景、社交参考分类。视频为活动／互动技术参考，不能直接认定是本公司场地、案例、客户或设备。

## 检查边界及重复

图片核对可见主要内容，未保证细小文字完整识别；视频仅查看每条10%、50%、90%的三帧，未完整观看、听音或转录。

36 个原文件的 SHA-256 全部不同。V002、V012 的全部音视频包 SHA-256 相同，说明包数据一致；原封装文件不同，仍保留两份并记录 `same_media_as`。其余视频未发现同包哈希重复；不等于排除了剪辑或局部内容相似。

`检查数据.json`、`检查拼图-*.jpg` 和 `视频检查-*.jpg` 为首次盘点及人工目视检查辅助资料；完整交付索引以 `素材清单.json` 为准。
