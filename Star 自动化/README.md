## 重建

运行 `python 整理资料.py`，需要现有 Python 环境中的 Pillow 及 PATH 中的 ffmpeg、ffprobe。脚本优先校验本机来源目录与归档原件；来源目录不在本机时，使用归档原件。文件集合变化或同名原件变化时会停止，需先核对并更新 `素材库/素材标注.json`。不覆盖变化原件，不删除重复文件。

## 维护规则

1. 原始资料留存原文，新增资料登记来源及接收日期。
2. 用户提供的信息保留来源标记；外部信息另记来源、查询时间和核验状态。
3. 未知内容保留为空或标注待补充，不推断行业、营业时间、价格或联系方式。
4. 图片和视频收到后登记文件路径、内容、用途、授权状态及 SHA-256；重复素材保留并标记。
5. 涉及中英文资料时分别保存原文，译文单独标注，逐项核对名称、地址、金额和服务内容。
