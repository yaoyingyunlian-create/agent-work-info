# 客服与预约约束

现有 11 组问答只覆盖纹眉，不适用于其他服务。原文件中的医疗级认证、绝不变色、敏感肌无刺激、碰水护理、麻药、价格包含项目、一个月内免费补色和付款顺序均待业务核验。知识条目不仅要已核验，还需 auto_reply_allowed=true 才可自动使用。

每半小时全天轮询意味着正常轮询延迟可接近 30 分钟；限流或故障可能更久。平台连接、持久游标、去重和调度不是插件技能文本自带的后台能力。未接通的平台只处理用户提供的消息草稿。

人工接管后停止自动发送；不跨账号混用客户资料。不把官网展示价格当作实时价格，不沿用 info@example.com 等疑似模板联系方式。

预约流程按门店配置可简化：申请、待客户确认、临时占位、待订金、已确认、完成、取消、未到场。每次变化记录预约 ID、版本、操作人、原因及系统回执。服务时长与清洁缓冲按具体项目和员工配置。UTC 存储时间，按确认的业务时区显示。

初始化 JSON 不是生产预约系统。需要实际支持并发占位、容量限制及改期事务的权威系统；不具备时只建申请，不虚构预约成功。
