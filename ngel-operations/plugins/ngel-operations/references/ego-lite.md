# Ego Lite 网页操作

网页操作统一使用 Ego Lite。运行前读取 ego-browser 技能，再运行 ego-browser skill 并遵循当前 CLI 指引。每个任务复用同一 TaskSpace，核对平台域名、业务账号及当前页面。首次登录、验证码和浏览器授权由账号持有人处理。任务中断或缺少权限时保留草稿，并说明需要处理的具体步骤。

发出回复、日报或提交预约前，核对已授权范围、目标、人工接管状态及上次操作结果。提交后读取页面回执。结果不明确时先核查，避免重复发送。预约页面必须能核验容量、确认结果和改期状态，否则只生成预约申请。

Codex 定时任务负责触发，Ego Lite 负责网页操作。任务运行主机需能访问已授权业务会话。先用只读操作验证页面，再用已授权测试账号验证写入回执。记录实际验证结果。
