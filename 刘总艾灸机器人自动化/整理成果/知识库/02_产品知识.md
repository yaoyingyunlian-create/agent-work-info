## 射频热疗机器人

来源：S006《射频热疗机器人产品手册 (2)》，17页，图片型PDF。下表为目视摘录，型号未明确。

| 参数 | 原手册值（第2页） |
| --- | --- |
| 重量 | 150 kg |
| 机体尺寸 | 650 × 830 × 1450 mm |
| 包装尺寸 | 800 × 1020 × 1630 mm |
| 电源输入 | AC 100—240 V，50—60 Hz |
| 额定功耗 | 400 W |
| 保险丝规格 | 220 V，10 A |
| 电源线长度 | 3.5 m |
| 使用环境 | 0—50℃，20%—80%相对湿度，非冷凝 |

功能摘录：高精度机械臂、柔性力控、自定义轨迹及参数（第2页）；可自定义力度、速度、能量、姿态、轨迹（第3页）；搭载门店管理系统（第2、9页）。这些参数需按最终交付型号、铭牌和正式说明书再核对。

资料问题：第9页正文出现“冲击波理疗机器人”“体外冲击波疗法”，与本文件的射频主题不同，视为疑似模板残留，不收录为射频功能。

手册第14页列有不适用人群和注意事项，涉及孕期/经期、体内金属或起搏器、肿瘤和严重疾病、局部皮损或骨折、子宫肌瘤/卵巢囊肿、行动能力丧失及经使用单位评估不适合的人群。此处仅用于定位原页，不作为完整筛查表；应取得正式说明书并由专业人员确认。该页也包含服务后注意事项，未独立医学核验。
