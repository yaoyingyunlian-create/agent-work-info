
# 输入、字段映射与判断口径

标准版单批 1–50 张，单附件不超过 20 MiB。文件路径可相对于批次 JSON。模板值为虚构示例。发票号码、税号和金额在 JSON、CSV 中使用文本，避免表格软件改写长数字。历史台账可用 UTF-8 或 UTF-8 BOM，参见 [CSV 模板](../assets/history.csv)。

## 列映射

按报销系统实际顺序填写 `columns`。报销系统的报销金额若与票面价税合计含义不同，请另设价税合计核对列，不自动换算或分摊。

| key | 票面语义 |
| --- | --- |
| kind / number / date | 票种 / 20 位发票号码 / 开票日期 |
| buyer / buyer_id | 购买方名称 / 购买方税号或统一社会信用代码 |
| seller / seller_id | 销售方名称 / 销售方税号 |
| item / remark | 项目名称 / 备注 |
| net / tax / total / rate / mode | 不含税金额 / 税额 / 票面价税合计 / 税率 / 计税口径 |
| fare / fuel / fund / other | 票价 / 燃油附加费 / 民航发展基金 / 其他税费 |
| travel_date / origin / destination / train / flight | 行程日期 / 出发地 / 到达地 / 车次 / 航班 |
| reason / file / custom | 消费事由 / 附件名 / 需人工补齐的其他业务列 |

`infer_reason` 默认为 false。明确允许时可从项目名称、车次或航班号生成带依据字段名的候选。业务事由缺失或候选待确认时，对账结论为未通过。金额、税号、日期均保留原始展示文本。

## 来源和观察记录

- **S1** 数电普票、专票原始 EInvoice XML 及铁路、民航开具端 XBRL 的已映射结构。入账端汇总 XML 可能缺少购方、票面日期和明细，请换票面原件。原始 XML 的其他变体需用样票确认映射。
- **S2** 按 OFD 文档声明读取页面 TextCode，或通过 pypdf 抽取 PDF 文本层。使用文本中同时包含字段和值的短证据。文本错序、多个候选或无法确定购销方归属时，留给人工核对。
- **S3** JPG、JPEG、PNG 或无文字层的 PDF/OFD。视觉读取依赖宿主能力。置信度必须由可解释的识别结果提供，模型不得为了达到阈值编造分数。看不清的字段可交 `evidence` 标出局部及疑似字符，`confidence` 留空。数值阈值 0.90 用于筛选，未经真实样本校准。
- 有多行税率时使用 `lines` 逐行提交金额、税额、税率，并确保所有明细行齐全。税率应保留百分号，或使用原 XML 中 0–1 的小数。S2/S3 只读票面明示字段，观察记录不得改写源文件或给缺字段补零。民航票价、燃油附加费、税额、基金、其他税费和合计按各自栏位读取。票面栏位缺失或语义不明则待人工确认。

下面是 S2 观察记录的字段片段。示例只展示一个字段，实际按对应票种补充所有能确认的字段。`sha256` 必须来自当批 inspect 文件的同一序号记录。

```json
{
  "observations": {
    "1": {
      "sha256": "替换为 inspect 得到的原始文件指纹",
      "fields": {
        "number": {"value": "26000000000000000001", "evidence": "发票号码：26000000000000000001"}
      },
      "lines": []
    }
  }
}
```

S3 条目格式为 `{"value":"原文","evidence":"首页右上角发票号码栏","confidence":0.95}`。票种使用原文字样，如“增值税专用发票”“普通发票”“航空运输电子客票行程单”“铁路电子客票”。铁路乘车票号和民航电子客票号均不可代替数电发票号码。

## 校验口径

- 20 位号码规则只用于本技能支持的四类数电票。全批及历史按完整票号精确比较，重复组整组拦截。期间按开票月，购方全称及税号在去除首尾空白后精确比较。
- 普票与专票优先按明细行做乘算，并与净额、税额合计互校。铁路按净额加税额及对应税率校验。民航使用票价、燃油、税额、基金、其他税费的加法，乘算以票价加燃油为基数。含退改或特殊计税且票面依据不完整时转人工。
- 免税、不征税只做加法。票面明确免税时，税额星号按零参与计算，展示仍保留票面星号。差额征税保留加法、跳过乘算并转人工。
- 容差包含边界，S1 为 0.00 元，S2 为 0.01 元，S3 为 0.02 元。乘算先用十进制定点四舍五入到分。全批对账独立执行，差额必须为 0.00，且行数、拦截、待补全部通过。
- 对账使用独立票面价税合计和实际底稿金额列。票据合计含拦截票据，底稿仅含可核对行。任何原始合计缺失时，差额显示无法计算。
