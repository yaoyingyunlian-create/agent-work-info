# 数字核对原型验证 · WB-20261120-01

仅为本地构造验证，不是可发布技能包。复用已有 inspect_artifact.py 的段落文字拼接。未安装新依赖，使用本轮 Python 3.12 隔离环境。

两份最小OOXML夹具各含正文与表格，独立真值清单共6个数，实际提取6/6。它们不是已用Office验证可打开的完整DOCX/PPTX，覆盖率不能外推真实交付物。

|字段|条件及操作|重算值|交付声明值|结果|
|---|---|---:|---:|---|
|status|精确等于已完成，计数|3|3|一致|
|amount|status精确等于已完成，求和，元|1234.56|1234.65|差异0.09元|
|amount|status精确等于已完成，均值，元|411.52|411.52|一致|

99999元的“进行中待复查未完成”行被排除，未按“完成”子串匹配。度量映射由显式条件提供，原型不从文件里的数字自行推断业务字段。缺字段、单位不同、空均值及损坏包会拒绝。原始数字均先标 unmapped，不自动放行业务结论。

验证脚本 validate.py 实际通过16项，包括四年级陪练预览。提取保留部件、段落与字符位置，输入两份夹具前后SHA256一致。原始结果见validation.json与recalculation.json；独立预期清单见fixtures/truth.json，源数据见fixtures/source.csv。

未验证：真实DOCX/PPTX、图片/OCR、图表、日期和编号分类、千分位数字、业务映射准确率、自动单位转换、真实Office打开渲染。还没有SKILL.md、ZIP或封面，不进入待发布。下一步对授权真实文档补测，并评估为既有验收技能扩展；不能直接新建SKU。
