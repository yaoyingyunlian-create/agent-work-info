# 质量与交付规则

生成前必须验证：题量为 5；难度为基础 2、进阶 2、挑战 1；能力类别不少于 4；每题 12 个必填字段非空；本次指纹无重复；档案用户近 60 天内没有相同指纹。

生成后必须验证：HTML 恰有两个 `class="page"` 区块；题目页 `class="q"` 与答案页 `class="a"` 各 5 个且编号 1 至 5；页眉练习编号一致并符合 `PB-YYYYMMDD-NN`；CSS 同时含 `@page { size: A4; }` 与 `page-break-after: always`。

题目页保留作答区和家长反馈栏。答案页逐题给出答案、分步思路、考查能力与常见误区。练习文本只使用“训练、辅助、建议”等非承诺性表述。
