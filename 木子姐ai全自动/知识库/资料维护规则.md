# 资料维护规则

版本：v1；更新：2026-11-24。用途：维护LA REINE / Yvelise知识与素材，不改变原文件引用路径。

## 新增资料

1. 判断来源、业务主题、原始/派生阶段和是否含敏感信息。密码、密钥、令牌不得放入文档、素材索引或共享导出；已存在敏感文件只记录需隔离，不回显内容。
2. 现有`原始资料/`与`官网资料/2026-11-24/`为已归档批次，保持原位。新用户资料可放`原始资料/YYYY-MM-DD-批次名/`；新官网采集放新的日期批次，不能覆写旧快照。
3. 人维护的业务知识继续使用`知识库/`；需要新增设计工程/编辑版本时使用`素材库/编辑源文件/`，发布审核通过的导出可使用`素材库/成品/`。这些目录仅在有真实资料时创建，不为了形式预建空目录。
4. 每份文档写用途、来源、来源日期、更新日期、状态。每份素材登记内容、场景、版本、来源/授权、阶段、AI状态及派生原件。不能确认的填“待确认”，未知日期不使用文件修改时间冒充。
5. 新资料的内容、标签和授权需由人确认后写入来源索引。自动索引能识别新文件及其类型，但不会替新素材编造业务描述。新增批次的映射适配前，来源/用途保留待确认。

## 命名与版本

新业务文档可用`主题-v1.0-YYYY-MM-DD.md`；新导出可用`商品或主题-用途-语言-v01.ext`。原始来件保留原名，不批量改名。版本号由内容负责人给定，不从尺寸或修改时间猜测。使用稳定ID关联原件、编辑源和导出，完整成分表与中英文应同步更新。

更新价格要记录币种、地区、SKU/套装范围、有效期及确认人。`API 0`不等于免费；“询价”与“未提供价格”分别记录。对外复用前复核价格、功效、资格与授权。

## 状态与归档

状态使用：来源记录、待确认、已确认（带确认人/证据/日期）、历史、废弃（带原因和确认）。同一文档可以是“原件归档已完成、业务内容待确认”。不能用下载成功、被官网引用或画面精美替代业务审核。

完全重复以SHA-256确认；相似画面、不同尺寸、不同语言或版本先建立关联，不能直接删除。优先通过索引推荐一个复用入口；保留全部被引用路径。确需移动/重命名时另列新旧路径、引用方、修复与验证方案，执行前先确认；本轮没有移动记录。

修复前文件在`整理过程/资料治理/修复前备份/`，仅供回溯。历史快照、生成输出与最终批准稿分开标记，默认不永久删除。对过期价格/方案先标“历史，待重核”，收到明确废弃结论后再登记。

## 安全刷新索引

在项目根目录执行：

```powershell
python -X utf8 整理过程/资料治理/维护索引.py
```

该工具仅扫描本地，生成自己管理的文件清单、素材清单、文档登记、引用关系、重复清单及校验结果，不联网、不移动、不删除、不重建原有HTML。生成文件末次哈希保存在`整理过程/资料治理/索引输出哈希.json`；检测到外部编辑即停止覆盖，应先检查差异。人维护的首页、问题清单、规则与整理记录不由它覆盖。

如增补或修改了其他既有文件，工具会在“相对本轮整理前基线”的变化中提示；这是追溯检查，不会回滚新修改。先核实变更，再独立保留新的日期基线，不能把所有变化自动判为损坏或静默重新授权。

## 现有工具的影响范围

| 工具 | 输入/主要写入 | 注意事项 |
| --- | --- | --- |
| 根目录`整理资料.py` | 固定桌面来件、原件/人工标注；写微信目录、预览、PDF页面与初始校验 | 固定63文件/60图/16页基线，不适合直接吞入新批次；可覆盖派生索引和PDF摘要 |
| `整理过程/官网采集/采集官网.py`等 | 写固定2026-11-24官网批次的原文与接口/资源清单 | 有联网和写文件副作用；持续维护应先建立新批次，不能把旧日期目录当最新 |
| `生成官网资料库.py` | 覆写官网产品Markdown/JSON/CSV、页面正文、预览和采集报告 | 已最小修复空价格覆盖问题；仍不能不看差异就运行，以免覆盖手工增补 |
| `校验官网资料.py`与`校验检索.cjs` | 校验之外还写原校验JSON | 它们不是纯只读命令；保留历史验证范围 |
| `修复询价展示.py` | 依据本轮基线做一次定向修复并备份 | 一次性迁移记录，不作为日常刷新工具，不重复运行 |

本轮静态引用检查覆盖文档/本地HTML、登记JSON路径及可解析脚本文字路径。动态路径、远端网站当前状态、完整UI和全部素材文字OCR需要另行验证，不能由静态检查自动宣布通过。
