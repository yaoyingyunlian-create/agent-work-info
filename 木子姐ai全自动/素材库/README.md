## 素材阶段

| 阶段 | 当前实例 | 使用原则 |
| --- | --- | --- |
| 原始素材/资料 | 微信图片与PDF；官网原始网络文件 | 保持原件，复用前确认内容与授权 |
| 编辑源文件 | 未发现可确认的PSD、AI、Figma、剪辑工程等 | 收到后连同软件版本、字体/链接资源、导出关系登记 |
| 中间产物 | 缩略图、PDF页面渲染、联系表、过程截图 | 用于检索/审阅，不能当作高分辨率成品或新增原始素材 |
| 网站尺寸变体/技术资源 | srcset图片、CSS引用文件、图标和字体 | 不同尺寸不能按重复删除；代码/字体按技术资源管理 |
| 最终成品 | 尚无已确认的发布成品清单 | 精美海报、产品图或官网正在引用的文件，不自动等于已批准最终稿 |
| 历史修复备份 | 本轮价格展示修复前的原文件 | 只用于回溯，不作为当前产品资料调用入口 |

用户附件及官网内容有已知来源，但素材是否AI生成多数没有生成记录。本轮统一标为“待确认”，不凭画面风格认定是真人拍摄或AI生成。生成的索引、摘要和缩略图属于辅助整理产物，不是原始产品证明。

## 复用前最短检查

查商品/主题 → 确认原件而非缩略图 → 读取状态和来源 → 核对中英文、价格、功效及授权 → 如需编辑，另存新版本并登记原件关系。当前库没有通过业务审批的发布状态，不把“已归档”改写为“可直接商用”。
