## 维护方式

`整理资料.py`以UTF-8读写，依赖Pillow和PyMuPDF（整理工具依赖；未建立应用服务）。直接运行复制并核验原件、生成图片联系表；运行 `python -X utf8 整理资料.py --build` 根据人工标注生成目录、PDF页面和校验报告。知识库Markdown由人工编辑，不会被目录构建覆盖。

人工标注用原始相对路径及SHA-256绑定，来源变化会中止构建。新增图片需要先补标注；本版校验固定63份原件、60图、16页，扩充批次后应同步更新基线，避免误报已覆盖新增资料。完整原文、对话发送人和聊天时间须另补，当前文件名不作为聊天时间证据。

官网批次工具位于 `整理过程/官网采集/`，独立于初始63份聊天原件及其校验基线。运行顺序为：`发现站点.py` → `采集官网.py`（页面）→ `采集官网.py --media-api` → `采集官网.py --content-api` → `采集官网.py --download` → `生成官网资料库.py`。工具使用本机已有requests、lxml、Pillow，不增加项目应用依赖。下载失败及校验范围以该批次的 `采集校验.json` 为准。

官网批次实际归档95个页面、40个商品地址及1269个下载资源URL（约211MiB）。公开媒体库返回180条记录，其中178条成功下载；另有1个失效占位图URL影响2条记录。接口响应头声明205条，复核分页仍仅返回180条，另25条内容未知、无法归档；未标记为“官网全部资源已抓齐”。

本轮资料治理保留原有路径，新增跨来源索引、文档状态、授权/AI来源待确认字段和维护规则。价格复核修正为21有价、14明确询价、5未提供价格；原始网页与接口未改，修复前派生文件保留备份。日常只刷新索引可运行 `python -X utf8 整理过程/资料治理/维护索引.py`；旧采集/生成器有覆盖副作用，先阅读维护规则，不直接重跑。
