# 定时任务

在 Codex 桌面端打开本项目，创建一个专用创作聊天。将以下七项建立为绑定该聊天的定时任务，时区为 Asia/Shanghai。每次沿用同一聊天和项目文件。Git 不会安装或启用 Codex 定时任务。先手动验证只读步骤，再按自己的授权启用。

每项提示词都加上这段公共前缀：

> 使用当前聊天关联的项目根目录。先读 README、策划/账号创作规则.md、策划/创作执行协议.md 和本文件；续用已有任务 ID。只操作本机已核对并明确授权的账号。实际失败写入项目日志，未知结果先回读。素材、凭据和生产记录保留在本机。

| 北京时间 | 重复 | 任务及提示词 |
|---|---|---|
| 08:40 | 每天 | 创作。读最近一次有效复盘，填写当日执行单。锁定30秒时间轴，先审关键首帧和动作，随后剪辑、核对口型声音、归档。生成前查规则、余额并报价。已有任务先取件。 |
| 11:00 | 每天 | 采集。用已授权的抖音创作者中心采集真实作品数据，记录作品ID、片龄和实际采样时间。更新待采窗口，保留缺项。 |
| 13:10 | 每天 | 补救。审计当日状态，接续既有任务并处理可修复的生成、剪辑和验收问题。避免重复扣费。 |
| 17:20 | 每天 | 发布。仅在本地账号授权有效时执行。核对当日作品的零字节 a.txt、当前文件哈希、标签最多5个、账号与查重结果。用平台作品ID和状态确认发布。 |
| 19:30 | 每天 | 互动。按本地授权看视频，按内容决定点赞或评论，优先回复本账号未回复的公开留言。记录互动对象和结果用于查重。 |
| 21:20 | 每天 | 回查日报。回查作品平台状态，汇总当日制作、发布、互动、数据和异常，并记录下一条可验证的改进。 |
| 22:30 | 周日 | 周复盘。按同片龄比较真实指标与样本量，复盘选题、开场、声音和返工，选一项改动落实到下周分镜。 |

新环境默认只读。实际生成需要 ThinkNova OAuth、余额和预算授权；发布与互动需要操作者本人登录 Ego Lite，并配置允许操作的账号与范围。原项目的聊天 ID、授权与登录态不随仓库迁移。
