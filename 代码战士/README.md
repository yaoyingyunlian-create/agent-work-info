# 古代侠女穿越现代阳新 · 数字人 IP

新系列讲一位武功盖世、会御剑飞行的古代侠女意外来到现代湖北阳新。她用旧本领应对现代难题，也逐渐认识这里的人。固定角色参考为 `数字人/02.png`，保留原五官、高髻、发簪、耳饰、白灰云纹衣、深色腰封与护腕，以及同一佩剑与剑鞘。创作与发布按项目规则执行。

## 新环境启动（Windows）

安装 Git、Python 3.11 或更新版本、FFmpeg（含 FFprobe）和 Node.js，并加入 PATH。在本目录执行：

```powershell
.\scripts\setup.ps1
py -3 -X utf8 scripts/build_media_catalog.py
py -3 -X utf8 scripts/production_audit.py --date (Get-Date -Format yyyy-MM-dd)
```

安装脚本只在工具包目录不存在时从官方仓库克隆。空项目审计应返回零成片，首次尚无制作账本属于正常状态。

在 Codex 中按官方工具包指引连接 ThinkNova MCP（https://api.thinknova.top/mcp）并完成本人 OAuth。角色参考、城市图片和剧情素材随项目提供。按素材来源记录核对使用范围，授权待确认的图片和视频仅作内部参考。发布和互动另需本人在 Ego Lite 登录并配置当地账号授权。定时任务的排程和逐项提示词见 [定时任务](运营/定时任务.md)。

历史发布成片、本地授权、聊天、凭据和运营账本由原操作者管理。下方目录和作品索引也说明本地运行后会产生哪些内容。

## 后续制作流程

主线与专用视频线程分工、任务续跑和异常恢复见 `策划/创作执行协议.md`；机器可读恢复点见 `策划/创作状态.json`。只读交付核对：`thinknova-toolkit-v3/.venv/Scripts/python.exe scripts/production_audit.py --date YYYY-MM-DD`。

1. 在 `策划/` 建立本集故事、台词和分镜。
2. 在 `成片/工作区/第NN集_主题/` 保存生成镜头、首帧、剪辑中间文件及检查结果；记录ThinkNova任务与素材ID。
3. 角色五官、发型和服装保持一致；避免把AI生成背景表述为实景。
4. 完成对白/字幕、封面和画面复核，再运行工具包质检并处理FAIL/WARN。
5. 只将最终发布文件及验收材料放入 `成片/YYYY-MM/作品名/`，遵守下节文件结构。
6. 没有本次明确授权时不登录、不发布。

### 本机质检

```powershell
$py = ".\thinknova-toolkit-v3\.venv\Scripts\python.exe"
& $py ".\thinknova-toolkit-v3\render\check.py" ".\成片\YYYY-MM\作品名\视频.mp4" --max-dur 35
```

工具包需要 Python、FFmpeg/FFprobe 和 Node.js；自动语音识别需兼容的 faster-whisper/PyAV 环境。不同环节检查失败时要记录实际情况，不能把未验证的字幕/验收写为已通过。

## 成片归档规范

```text
成片/
└─ YYYY-MM/
   └─ 作品名/
      ├─ 标题.txt
      ├─ 发布文案.txt
      ├─ 标签.txt
      ├─ 封面.jpg
      ├─ 视频.mp4
      ├─ 视觉质检.json
      ├─ 验收材料/
      │  ├─ 对白.lrc
      │  └─ 分镜.md
      └─ 质检证据/
         └─ 抽帧_*.jpg
```

- `标题.txt`仅保存一条标题；`发布文案.txt`保留抖音发布换行；`标签.txt`一行保存全部标签。
- 质检 JSON 记录真实抽帧路径、检查项、分镜数、独立背景数和结论；抽帧随作品归档。
- 月度作品目录只放最终发布文件和验收材料，不放剪辑工程、原始生成视频及无关中间素材。
- 技术质检有FAIL，或音频、授权、字幕同步、人工终审仍未完成时，不得标为可发布。

### 5.3 复查标记 `a.txt`

只有作品通过全部复查项后，才在作品目录根部创建 **0字节空文件** `a.txt`。它表示“素材已复查，可进入人工发布流程”，不代表作品已经发布。

- 音频、字幕、授权、封面、技术质检或人工终审任一项未通过时，不得创建 `a.txt`。
- 修改已有标记作品的封面、视频、标题、文案或标签后，必须先删除旧 `a.txt`，重新复查全部项目后才能重建标记。
- 自动化只能在全部复查通过后创建该标记；自动化不负责登录或发布。
